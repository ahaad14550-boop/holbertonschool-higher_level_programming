# JavaScript DOM Manipulation

This repository contains a set of exercises focused on manipulating the Document Object Model (DOM) using vanilla JavaScript. The goal is to learn how to interact with HTML elements dynamically by selecting, modifying, creating, and deleting nodes in a web page.

## Project Overview

Each script demonstrates a different DOM manipulation technique, including:

- Selecting elements with `getElementById`, `querySelector`, and `querySelectorAll`
- Changing element content, styles, and attributes
- Creating and inserting new elements
- Handling events and updating the page dynamically
- Working with lists and forms in the browser

## File Structure

The `javascript-dom_manipulation` folder includes:

- `0-main.html`: Example HTML file used to test the DOM scripts
- `0-script.js` through `100-script.js`: JavaScript exercises that perform DOM operations
- `README.md`: This project description

## How to Use

1. Open one of the HTML files in a browser.
2. Include the corresponding script file with a `<script>` tag, or open the HTML file directly if the script is already linked.
3. Inspect the page and the browser console to verify DOM updates.

## Learning Objectives

By completing the exercises in this project, you should be able to:

- Understand the structure of the DOM and how web pages are represented as nodes.
- Access and modify HTML elements from JavaScript.
- Build interactive web pages without relying on external frameworks.
- Write clean, modular code for DOM updates and event handling.

## Notes

These exercises are designed for learners practicing JavaScript fundamentals and browser scripting. They provide a solid foundation for building more advanced client-side applications.
